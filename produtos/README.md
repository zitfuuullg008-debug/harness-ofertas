# produtos/

Uma ficha `.md` por produto. Copie `_TEMPLATE.md`, renomeie (ex.: `pao-de-queijo-recheado.md`) e preencha.

Os agentes **ideador** e **criativos** leem TODAS as fichas desta pasta (menos as que começam com `_` e este README).
Sem ficha aqui, o agente de criativos não gera nada — de propósito, pra nunca criar no escuro.
